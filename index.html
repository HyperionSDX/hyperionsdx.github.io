Prisma

Asistente personal para DiscordPersonal assistant for Discord

Un bot que ordena el día: resumen de la mañana con clima, agenda y noticias explicadas por IA, recordatorios, conversación con fotos y documentos, y avisos cuando algo cambia en una página o un precio.

A bot that organizes the day: a morning briefing with weather, schedule and AI-explained news, reminders, conversations with photos and documents, and alerts when a web page or a price changes.

  • Panel web instalable en el celular, con inicio de sesión de dos pasos y niveles de acceso.
  • Prisma Security: guardián en GitHub Actions que revisa todo cada hora, intenta repararlo y explica en palabras simples lo ocurrido.
  • Funciona en más de un servidor: detecta dónde está, despliega ahí y se muda con un solo comando.
  • IA con respaldo en cadena (Groq, Gemini y un modelo propio) para no quedarse sin respuesta.
  • Web dashboard installable on a phone, with two-step sign-in and access levels.
  • Prisma Security: a GitHub Actions watchdog that checks everything every hour, tries to fix problems and explains in plain words what happened.
  • Runs on more than one server: it detects where it lives, deploys there and moves with a single command.
  • AI with a fallback chain (Groq, Gemini and a self-hosted model) so it always has an answer.

Plays from YouTube, Spotify, SoundCloud and Apple Music, with controls, a web dashboard and five languages remembered across restarts.

  • Diagnóstico y corrección de un corte de audio a los 120 ms (PCM sin cabeceras pasando por un segundo FFmpeg).
  • Si una pista falla, la busca en otra fuente y sigue sonando.
  • Diagnosis and fix of audio cutting out after 120 ms (headerless PCM going through a second FFmpeg).
  • If a track fails, it finds it on another source and keeps playing.

Cómo funciona PrismaHow Prisma works

  1. Discord: escribes y Prisma responde.
  2. Prisma, en un servidor con Docker (Oracle o Azure), consulta a la IA (Groq o Gemini) cuando hace falta.
  3. Panel web: lo controlas desde el celular, con inicio de sesión de dos pasos.
  4. GitHub Actions prueba cada cambio, lo despliega y vigila que todo funcione.
  5. La página de estado muestra en público lo que está en línea.
  1. Discord: you write and Prisma answers.
  2. Prisma, on a Docker server (Oracle or Azure), asks the AI (Groq or Gemini) when needed.
  3. Web panel: you control it from your phone, with two-step sign-in.
  4. GitHub Actions tests every change, deploys it and watches that everything works.
  5. The status page publicly shows what is online.
